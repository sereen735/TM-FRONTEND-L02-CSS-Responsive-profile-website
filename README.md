# 🌟 Responsive Personal Profile Website

A responsive single-page personal portfolio website built using **HTML5** and **CSS3** as part of the **TechMood Front-End Bootcamp**. This project focuses on modern layouts, Flexbox, CSS Grid, and responsive design principles.
> 🔗 **Live Preview:** https://responsive-personal-profile7.netlify.app/

## 📁 Repository Structure

- **02-CSS/**
  - **Lesson-02/**
    - **Responsive-Profile-Website/**
      - 📄 `index.html` (Main single-page portfolio layout)
      - 🎨 `style.css` (Custom CSS styles and responsive design)
      - 🖼️ `images/` (Project assets and profile photo)

## 🛠️ Technologies Used

- **HTML5:** Semantic elements, structure, forms, and layout.
- **CSS3:** Flexbox, CSS Grid, and responsive media queries.
- **Git & GitHub:** Version control and repository management.
